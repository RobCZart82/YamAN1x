# MAME Research Instructions

This directory contains the reproducible, pinned-source MAME investigation used
by the YamAN1x project. The research target is separate from the plugin core. It
uses local Yamaha firmware as a read-only input; ROM images, captures and
compiled research artifacts are not repository content.

The detailed build commands, patch-chain description, run profiles and historical
experiment notes are currently maintained in Hungarian in
[README_HUN.md](README_HUN.md). The English project status and technical
acceptance limits are in [the main status](../docs/STATUS.md) and
[the first REAPER sound plan](../docs/FIRST_REAPER_SOUND_PLAN.md).
